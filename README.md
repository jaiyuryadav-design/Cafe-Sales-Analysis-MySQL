# ☕ Cafe Sales Analysis using MySQL

## 📌 Project Overview

This project is an end-to-end SQL data analysis project based on cafe franchise sales data.

The project covers the complete process from importing and cleaning raw data to performing exploratory data analysis (EDA) and advanced business analysis using MySQL.

The analysis focuses on outlet performance, sales trends, products, customers, payment methods, ratings, and revenue growth.

## 🧹 Data Cleaning

The raw dataset was cleaned and standardized before analysis.

Key cleaning steps:

- Identified missing and blank values
- Standardized city names
- Standardized outlet names
- Filled missing cities using outlet information
- Identified and removed duplicate records
- Validated quantity and price values
- Converted multiple date formats into a standard DATETIME format
- Created separate Order Date and Order Time columns
- Cleaned customer names
- Validated customer ratings
- Standardized franchise owner information
- Standardized payment methods

---

## 📊 Exploratory Data Analysis

The following business questions were analyzed:

1. Total revenue generated by each outlet
2. Highest-selling product overall
3. Best-selling product for each outlet
4. Year-wise sales trends
5. Month-wise sales trends
6. Payment mode distribution
7. Average Order Value (AOV) by outlet
8. Relationship between customer ratings and sales
9. Year-over-Year (YoY) outlet growth
10. Weekday vs Weekend sales performance
11. Low-rated but high-selling products
12. Customer repeat-purchase patterns

---

## 💡 Key Insights

- Surat ranked as the highest revenue-generating outlet.
- Bengaluru recorded the highest YoY growth in 2025 at approximately 3.19%.
- Ratings showed almost no linear relationship with sales.
- Weekend and weekday average daily sales were relatively similar.
- Several high-selling products also had relatively low customer ratings.
- Repeat-purchase analysis identified customers who placed multiple orders.
- Monthly sales showed both positive and negative growth periods.

## ⚙️ Stored Procedure

A stored procedure named `GetMonthlyOutletReport` was created to generate a monthly performance report for any selected cafe outlet.

The report provides:

- Sales Year
- Sales Month
- Total Orders
- Total Revenue

Example:

CALL GetMonthlyOutletReport('Ajey''s Cafe - Surat');
